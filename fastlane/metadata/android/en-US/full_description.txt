<p><i>WoouSU</i> is a KernelSU-based, kernel-level root solution for Android. It provides kernel-based <code>su</code> with allowlist-based access control, an overlayfs module system, App Profiles and kernel umount. It is not tied to a specific device: install the manager, patch your stock <code>boot</code> / <code>init_boot</code> image, flash it, and you have root.</p><p>Optional SUSFS support (sus paths, sus mounts, mmap hiding, kstat and uname spoofing) is available when the kernel is compiled with the SUSFS patches. A prebuilt OnePlus 10T / Ace Pro kernel is provided as a convenience, not as a device restriction.</p><p>Requires Android 12+ and an unlocked bootloader. Current ABI: <code>arm64-v8a</code>.</p>
